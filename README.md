### 香港 VPS 是否一定比美国 VPS 快？

可以。官方列出的系统包括 Ubuntu、Debian、AlmaLinux、RockyLinux、CentOS、CentOS Stream 和 Fedora 等，也支持手动 ISO 安装。

### 40G 套餐能不能跑 WordPress？

官网香港方案页面显示包含免费自动备份和免费快照。实际使用时仍应确认保留周期、恢复方式和具体限制，并额外保留异地备份。
